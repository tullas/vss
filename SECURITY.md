# Security policy

VSS accepts private vulnerability reports through GitHub Security Advisories for
`tullas/vss`. Do not include credentials, production data, or exploit material
in public issues. Include affected versions, impact, reproduction conditions,
and suggested mitigations when available.

The project acknowledges a report within five business days, assigns severity
and ownership, and follows the remediation targets in
[`docs/security/vulnerability-management.md`](docs/security/vulnerability-management.md).
Only the current `main` branch and releases explicitly listed as supported are
eligible for security fixes. There are no currently published supported binary
releases.

Repository controls support secure-development assurance; they are not a claim
of certification or compliance with NIST SSDF, SLSA, or OpenSSF programs.
