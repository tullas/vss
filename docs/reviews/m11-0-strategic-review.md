# M11.0 Strategic Review — First Governed Moving Shot

## Scope and concern

Issue #132 correctly identifies Film #1's missing observable audiovisual
capability: its current ladder ends at an integrity-bound still image. The
proposed one-shot image-to-video request would, however, cross from the
current local still-review path into an external, effectful media and cost
boundary. The review concerns whether that boundary is admitted before a
provider is selected or a paid request is attempted.

- `KEEP`: Film #1 as the proving application; Runtime as the only execution
  authority; human-triggered creative and production decisions; exact lineage
  from source shot and admitted visual basis.
- `CHANGE`: split the requested outcome into an architecture-admission
  decision followed by the first bounded moving-shot implementation. The
  implementation must not invent a generalized video framework, queue, or
  autonomous retry loop.
- `RESEARCH`: the smallest admissible provider contract, immutable source and
  output lineage, one-attempt budget reservation, and controlled local-media
  handling for the selected provider.
- `REMOVE/RETIRE`: none.
- `DO_NOT_BUILD`: a Studio Director, critic/agent loop, generalized video
  platform, durable worker/queue, editor, audio pipeline, or publication path.
- `BIGGEST_WRONG_ASSUMPTION`: that a local clip and a one-call spend ceiling
  can be represented safely by the existing semantic/still-review boundaries.
- `MISSION_ALIGNMENT`: `ALIGNED_WITH_DRIFT_RISK`.

## Disposition

`REMEDIATE_FIRST`. The next bounded work must establish the already-deferred
Asset/Data, output-admission, and resource-admission seams before Issue #132
can select a video provider or make an external request. This is a direction
review only and grants no Runtime, provider, production, publication, budget,
or approval authority.
