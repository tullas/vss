## Integrated progression

M6 is a coherent, bounded semantic progression:

`shot_cinematography_observation/1` (manual/synthetic observation)
→ bounded observation Set and immutable Context
→ deterministic recurrence/variation Pattern
→ Context-scoped Lesson Candidate
→ explicitly human-admitted, exact-project Shot/Cinematography Knowledge.

Each boundary has its own exact contract, digest and validation semantics.
Observation, Pattern, Lesson Candidate, and Admitted Knowledge remain
non-truth, non-authorizing artifacts. No step performs automatic promotion.

## M6.5 governance result

Admission requires a human actor and an integrity-bound admission decision.
Only local manual or synthetic provenance is accepted. Knowledge is restricted
to one project and the Shot/Cinematography domain; it does not generalize to a
studio, project family, or universal cinematography rule.

Candidate, Pattern Set, Pattern, Context, provenance, and digest lineage are
independently revalidated before admission. Challenge, supersession,
withdrawal, and revocation are immutable lifecycle events. Current-use
eligibility fails closed for missing, malformed, ambiguous, adverse, future, or
substituted lifecycle/evidence state, while historical artifacts remain
interpretable. Knowledge does not authorize Runtime, recommend creative action,
or create a promotion path.

## Architecture checkpoint

ReasoningGateway: `HEALTHY_WITH_PRESSURE`. It remains semantic-only and no
Runtime authority has moved into the Gateway. Repeated exact lifecycle adapters
are visible across M5/M6, so Gateway extraction should be reconsidered only if
another independent domain creates correctness-relevant duplication.

ADRL-002: `WAIT_FOR_EVIDENCE`. M6 supplies repeated same-domain evidence
binding, but not enough independent semantic domains or simplification evidence
to admit a generic framework.

Registry and version pressure remain acceptable: four federated registries,
exact dispatch, no wildcard/latest/range fallback, and no instance registry.
Movie registry growth is legitimate contract registration only. PR #79's
repository-owned schema/registry caching remains intact; untrusted artifacts
continue to be independently validated.

No M6 concept is justified for removal. The separate Set, Context, Pattern,
Lesson Candidate, admission decision, Knowledge, and lifecycle boundaries carry
distinct scope, authority, or provenance semantics. No generic lifecycle,
evidence, or Knowledge framework should be introduced yet.

## Mission and next milestone

M6 is complete for its original mission contribution: VSS can carry governed
local cinematography evidence from observation through reusable, human-admitted
semantic Knowledge without confusing semantics with truth or execution
authority.

The next implementation milestone should be a narrow, deterministic use of
admitted Shot/Cinematography Knowledge in an existing production-option path,
with exact scope and explicit non-authorizing output. It should consume
Knowledge; it must not create another epistemic layer or automatic promotion.
Any creative option remains subject to the existing human/Runtime authority
boundaries.

Deferred: richer observation vocabulary, external/reference learning,
AI/CV/media observation, probabilistic confidence, cross-project Knowledge,
recommendation/Creative Intent, Shot Design, Plan IR, and Data/Compute or
rendering infrastructure. Reconsider each only through a separate milestone
and architecture review with concrete evidence.
