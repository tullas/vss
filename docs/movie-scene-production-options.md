# M4.3 Deterministic Scene Production Options

M4.3 assembles exactly one validated Scene Breakdown scene into a bounded
`scene_production_options_context/1` and emits a fixed catalogue of inert
alternatives. Catalogue order is stable ordering, never ranking or selection.

The initial profiles are `minimal_stage`, `location_live_action`, `stylized_2d`,
and `stylized_3d`. They contain qualified broad considerations only. No option
claims feasibility, cost, duration, rights clearance, quality, availability, or
artistic superiority. Options are not plans, approvals, schedules, budgets,
asset manifests, or execution instructions.

The provider-visible view is immutable and minimized to the selected scene,
qualifications, uncertainty, limitations, evidence identifiers, profile
catalogue identity, and bounds. No external AI, prompt, connector, retrieval,
media generation, Plan IR, approval, or execution exists. Trusted Python remains
in-process and local JSONL remains development-only.
